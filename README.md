# Sistema Bancário Simplificado

Olá, pessoal! Bem-vindos ao meu novo projeto!

## 🎯 Finalidade do Projeto

Este projeto foi desenvolvido exclusivamente para fins de estudo, baseado no desafio técnico de uma empresa bancária do Brasil disponibilizado publicamente no GitHub.

O foco principal não é concluir 100% do desafio, mas sim **praticar e consolidar novos conceitos** .

## 🚀 Conceitos e Objetivos

| Conceitos a aplicar | Objetivo |
| :--- | :--- |
| **Spring Boot Security** | Aplicar autenticação e autorização com tokens, validações, roles, etc. |
| **Transactional** | Cuidar para que toda movimentação e operação no banco aconteça de forma segura. |
